## Publicar con GitHub Pages
1. Abre **Settings → Pages** en este repositorio.
2. En **Build and deployment**, elige **Deploy from a branch**.
3. Selecciona la rama `main` y la carpeta `/ (root)`, y guarda.
4. Revisa la URL que muestre GitHub Pages cuando termine el despliegue.

Las fotografías de repostería son de referencia y pueden cambiarse por fotos reales del negocio. Los enlaces de Facebook y TikTok están pendientes de recibir.
